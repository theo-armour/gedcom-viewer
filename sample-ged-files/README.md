# GEDCOM Files

tags #GEDCOM

Sample family trees for trying out the viewer. They're all in its File menu as "sample: …". When you read this page in the viewer (📄 Read me… → Sample files), click a file name marked 🌳 to open it in the viewer. Each file is kept exactly as downloaded, apart from Kennedy, which came zipped.

## Acknowledgements

* **webtreeprint.com** publishes Brontë, Shakespeare, Royal92 and the presidents as its "famous GEDCOMs", free to download.
* **Brontë and Shakespeare** were compiled by webtreeprint.
* **The US presidents** (`pres2020.ged`) was made in Family Tree Maker. webtreeprint says it was updated to 2020, with thanks to Paul Stobbe. Its notes quote other published sources, which carry their own copyright lines.
* **Royal92** was compiled by Denis R. Reid and published in November 1992. In a message quoted in the file's header, he wrote: "You may make this Royal GEDCOM available to whomever." He asked that anyone passing it on add that he would welcome comments, suggestions and sources to improve it. Since 1992 it has been a classic test file.
* **Gramps sample** is the example tree from [Gramps](https://gramps-project.org/), the open-source genealogy program. It's copyright 2010 Alex Roitman and is distributed with Gramps under the GNU GPL. The people in it are made up.
* **Kennedy** is the sample tree shipped with Chronoplex's [My Family Tree](https://chronoplexsoftware.com/myfamilytree/) program. It downloads as `The Kennedy Family.gdz`, a zip holding the tree and 10 photos. Only the tree, `gedcom.ged`, is kept here, renamed `kennedy.ged`.
* **Topola Viewer** suggested the Kennedy and Shakespeare files, which it uses as its own examples. It also shows a third example, Maria Skłodowska-Curie, which isn't a file: Topola reads her family live from [WikiTree](https://www.wikitree.com/wiki/Sk%C5%82odowska-2).
